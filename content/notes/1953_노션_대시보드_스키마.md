# 1953형제돼지국밥 Notion 대시보드 스키마 (프로토타입)

## 🎯 크롤링 타겟 전략 (Phase 1 vs Placeholders)

**Phase 1 (우선 구현 타겟 - 프로토타입용)**

- **소스**: 네이버 플레이스 방문자 리뷰
- **지점**: 경성대 본점 (가장 데이터가 많을 것으로 예상되는 메인 타겟)

**Phase 2 (Placeholders - 미팅 후 확장 예정)**

- **소스**: 인스타그램 해시태그(`#1953형제돼지국밥`), 배달의민족/요기요 리뷰
- **지점**: 광안리점, 서면점, 사직점, 중앙점, BIFC문현점 등 전 지점

## 🗄️ Database: 리뷰 통합 모니터링 보드

n8n을 통해 실시간/일간으로 들어올 리뷰 데이터를 담는 노션 데이터베이스의 컬럼(Property) 설계입니다.

| 속성명 (Property) | 타입 (Type)    | 옵션 (Options) / 설명                                       |
| :---------------- | :------------- | :---------------------------------------------------------- |
| **한줄 요약**     | `Title`        | AI가 원문을 읽고 작성한 15자 이내 핵심 요약                 |
| **지점명**        | `Select`       | **경성대 본점**, `[광안리점]`, `[서면점]` ...               |
| **출처**          | `Select`       | **네이버 플레이스**, `[인스타그램]`, `[배달의민족]` ...     |
| **작성일자**      | `Date`         | 리뷰가 실제 작성된 날짜                                     |
| **감성 평가**     | `Select`       | 🟢 긍정(Positive) / 🟡 중립(Neutral) / 🔴 부정(Negative)    |
| **핵심 키워드**   | `Multi-select` | 맛, 서비스, 위생, 가격, 대기시간(웨이팅), 인테리어          |
| **언급된 메뉴**   | `Multi-select` | 맑은국밥, 뽀얀국밥, 불꽃돼지국밥, 수육백반, `[마라국밥]`... |
| **원문 링크**     | `URL`          | 해당 리뷰로 바로가는 링크                                   |
| **리뷰 원문**     | `Text`         | 사용자가 남긴 텍스트 전문                                   |
| **AI 코멘트**     | `Text`         | 예: "고기 냄새에 대한 불만 제기됨. 주방 확인 필요"          |

## 📈 View (화면 보기) 구성 아이디어

1. **전체 보기 (Table View)**: 최근 들어온 순서대로 모든 데이터를 엑셀처럼 나열
2. **긴급 대응 보드 (Board View)**: `[감성 평가]`가 **🔴 부정(Negative)**인 리뷰만 필터링하여 카드 형태로 배치. 담당자가 처리 후 '완료' 처리할 수 있도록 칸반(Kanban) 보드화
3. **지점별 현황 (Gallery View)**: 지점별로 그룹화하여 긍정/부정 비율을 시각적으로 확인
