# 모던 디자인 핸드오프: 스펙 시트가 필요 없는 파이프라인

지금까지 다룬 규칙들(수학적 타이포그래피 렌더링, 오토레이아웃, 디자인 토큰)이 모이면 디자인 핸드오프(Handoff) 과정은 완전히 다른 차원으로 진화합니다.

## "해석"이 아닌 "복사"

과거 Zeplin 시대에는 개발자가 빨간색 점선을 보며 마진을 해석하고 눈대중으로 옮겼습니다. 하지만 모던 시스템에서는 다음과 같이 일합니다.

1. **간격 고민 제로**: `gap: var(--spacing-md)`
2. **반응형 고민 제로**: Figma에 걸려있는 Min-width 제약을 그대로 코드에 복사.
3. **수직 정렬 논쟁 종결**: Cap-centered 폰트 덕에 "왜 브라우저에선 위로 쏠리죠?" 라는 질문이 사라집니다.

## 더 나아간 픽셀 퍼펙트: 복사조차 생략하는 "자동화"

최신 실무 파이프라인은 복사/붙여넣기조차 생략합니다. **Token Studio** 플러그인이나 **Figma REST API**를 활용해, 디자이너가 Figma에서 값을 수정하면 GitHub Actions가 이를 감지하여 개발 저장소로 PR을 쏴줍니다.

```javascript
// 자동 추출된 tailwind.config.js 예시 (디자이너가 배포)
module.exports = {
  theme: {
    colors: {
      primary: 'var(--color-primary)', // Figma 변수에서 자동 주입됨
    },
    spacing: {
      md: '16px', // 디자이너가 Figma에서 간격을 20px로 수정하면 이 파일도 자동 업데이트됨
    },
  },
};
```

## 결론: 코드로 작동하는 디자인

궁극적인 픽셀 퍼펙트는 **"디자인 파일 자체가 이미 하나의 코드 베이스처럼 작동한다"**는 것을 의미합니다. 디자이너가 웹 생태계의 렌더링 구조를 이해하고, 개발자가 토큰 시스템을 존중할 때 팀은 비로소 단일 진실 공급원(SSOT) 위에서 춤출 수 있습니다.
