# [미팅 준비] 1주차 킥오프 및 요구사항 정의

## 🗣️ 1. 기업/멘토 대상 질문 리스트 (요구사항 수집)

킥오프 미팅에서 프로젝트의 범위를 명확히 좁히기 위해 확인해야 할 필수 질문들입니다.

### A. 크롤링 타겟 및 범위

- [ ] **메인 채널 우선순위**: 블로그(네이버/티스토리), 인스타그램, 커뮤니티, 배달앱(배민/요기요), 지도(구글/네이버/카카오) 중 가장 우선적으로 모니터링하고 싶은 채널 TOP 3는 무엇인가요?
- [ ] **핵심 키워드**: "1953형제돼지국밥", "형제돼지국밥" 외에 추적해야 할 경쟁사 키워드나 특정 메뉴명(밀키트 등)이 있나요?
- [ ] **수집 주기**: 실시간(혹은 1시간 단위)으로 수집해야 하나요, 아니면 하루 1번 자정 배치(Batch) 작업으로 충분한가요?

### B. AI 분석(OPAL, AI Studio) 방향성

- [ ] **감성 분석 뎁스(Depth)**: 단순히 긍정/부정/중립만 나누면 될까요? 아니면 [맛, 가격, 위생, 친절도, 분위기] 등 특정 카테고리별 평가를 원하시나요?
- [ ] **요약 리포트**: 주간/월간 리포트가 생성될 때, 담당자가 가장 보고 싶어 하는 핵심 인사이트(예: 불만 폭증 알림, 신메뉴 반응 등)는 무엇인가요?

### C. 인프라 및 예산

- [ ] **계정 및 API 키**: n8n 구동을 위한 서버(로컬 vs 클라우드 VM) 지원 여부와, Google OPAL / AI Studio API 호출 비용(프로젝트 실행비) 결제 방식이 어떻게 되나요?

## 📊 2. Notion 대시보드 스키마 (초안)

기업 측에 "이런 식으로 결과물을 보시게 될 겁니다"라고 제안할 노션 데이터베이스 뼈대입니다.

### 🗄️ Database 1: 📡 실시간 리뷰 모니터링 (Raw Data)

n8n이 크롤링하고 AI가 분석한 데이터가 건별로 즉시 쌓이는 DB입니다.

- **이름 (Title)**: AI가 요약한 한 줄 제목 (예: "국물은 진하나 배달이 늦었다는 리뷰")
- **채널 (Select)**: 네이버 블로그, 인스타그램, 배달의민족 등
- **원문 링크 (URL)**: 해당 게시글 바로가기
- **수집 일시 (Date)**: 크롤링된 시간
- **감성 (Select)**: 🟢 긍정 / 🟡 중립 / 🔴 부정
- **카테고리 (Multi-Select)**: 맛, 서비스, 배달, 가격, 매장 분위기
- **원문 내용 (Text)**: 원본 텍스트 전체
- **AI 인사이트 (Text)**: AI가 남긴 코멘트 (예: "고기 양에 대한 불만이 언급됨. 매장 확인 요망")

### 🗄️ Database 2: 📈 주간/월간 리포트 (Insights)

주말에 n8n이 1주일치 DB를 묶어서 AI에게 던져준 뒤, 요약 리포트 페이지를 생성해주는 DB입니다.

- **리포트 주차 (Title)**: 2026년 7월 1주차 브랜드 반응 리포트
- **총 언급량 (Number)**: 154건
- **긍정 지수 (Number/Progress Bar)**: 82%
- **핵심 키워드 (Multi-Select)**: #밀키트품절, #육수진함, #웨이팅
- **액션 아이템 (Text)**: AI가 제안하는 이번 주 마케팅/운영 개선 포인트
