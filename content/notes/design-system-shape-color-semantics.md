# 디자인 시스템의 형태와 색상 의미론 (Shape and Color Semantics)

디자인 시스템을 구축하고 운영할 때, UI 컴포넌트의 가짓수를 무한정 늘리지 않으면서도 명확한 커뮤니케이션을 하기 위해 **색상(Color)**과 **형태(Shape)**의 역할을 엄격하게 분리하는 것이 글로벌 테크 기업(Atlassian, GitHub Primer, Apple HIG 등)의 업계 표준(Standard)입니다.

## 1. 색상(Color)은 '상태와 감정'을 전달한다

색상은 인간의 본능적인 인지 영역에 직접적으로 작용합니다. 따라서 디자인 시스템의 시맨틱 컬러(Semantic Color)는 특정한 상태나 감정을 일관되게 나타내야 합니다.

- 🔴 **Danger / Error:** 치명적 오류, 삭제, 실패
- 🟡 **Warning:** 주의 필요, 진행 중, 미완성
- 🔵 **Info:** 정보, 안정적, 자라나는 중
- 🟢 **Success:** 완료됨, 긍정적, 영구적

**블로그 메타데이터에의 적용 (디지털 정원 성숙도)**
디지털 정원(Digital Garden)의 문서 성숙도 개념은 이 시맨틱 컬러와 완벽하게 멘탈 모델이 일치합니다.

- 🌱 **Seed (작성 중인 글):** `Warning` (노랑/주황 계열)
- 🌿 **Sapling (살이 붙은 글):** `Info` (파랑 계열)
- 🌲 **Evergreen (완성된 상록수 글):** `Success` (초록 계열)

새로운 색상을 하드코딩하여 만들지 않고, 이미 검증된 위 3가지 디자인 시스템 컬러 토큰을 100% 재사용(Mapping)하는 것이 핵심입니다.

## 2. 형태(Shape)는 '맥락과 종류(Context)'를 전달한다

단순히 색상만으로 모든 것을 표현하면, 블로그의 문서 상태(Seed)와 실제 시스템 경고(Warning 알림)가 시각적으로 동일해져 사용자에게 혼란을 줄 수 있습니다. 이를 방지하기 위해 형태(Variant)로 맥락을 분리합니다.

- 💊 **완전 둥근 알약(Pill) 모양:**
  - **용도:** '현재 상태(Status)', '수치(Count)' 등 해당 요소의 메타데이터를 나타낼 때 주로 사용.
  - **적용:** 블로그 글의 성숙도 뱃지 (Seed, Sapling, Evergreen)
- 🏷️ **모서리만 살짝 둥근 네모(Label) 모양:**
  - **용도:** '분류(Category)', '태그(Tag)'를 나타낼 때 주로 사용.
  - **적용:** 글의 태그 목록(React, Design System 등) 또는 진짜 시스템 경고 창.

## 결론 및 레슨 런

형태와 색상의 역할을 이처럼 교차해서 조합하면, 컴포넌트를 무한정 늘리지 않고도 사용자가 헷갈리지 않는 명확한 UI를 제공할 수 있습니다. 무의식적으로 디자인 시안에서 Pill 형태와 Label 형태를 나누어 설계한 것은 이러한 업계 표준의 멘탈 모델을 이미 직관적으로 이해하고 있었음을 보여주는 좋은 사례입니다.
