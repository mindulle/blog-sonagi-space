# 기능 명세서: 디지털 정원 시리즈 & 승격(Maturity) 파이프라인

## 1. 개요 (Overview)

본 문서는 소나기 블로그(Digital Garden)의 핵심 아키텍처인 "파편화된 위키 노트가 어떻게 블로그의 정식 연재물(Series)과 상록수(Evergreen) 글로 승격되는가"에 대한 정책과 UI/UX 명세를 정의한다.

---

## 2. 지식 승격 파이프라인 (Wiki -> Blog)

### 2.1. 목적

- 자유롭고 거친 위키의 작성 환경(Obsidian 등)을 침해하지 않는다.
- 명시적인 의도가 있는 글만 블로그(`content/notes`)로 배포하여 품질을 보장한다.

### 2.2. 상태(Status)의 정의

블로그의 글은 3단계의 성숙도를 가진다. (UI 상에는 GrowthBadge로 노출됨)

1. **Seed (씨앗)**: 아이디어 스크랩, 러프한 초안. (블로그 노출은 되나, 다듬어지지 않음)
2. **Sapling (묘목)**: 어느 정도 구조가 잡히고 내용이 채워진 상태.
3. **Evergreen (상록수)**: 타인에게 읽히기 위해 정제와 윤문이 완료된 완성된 글.

### 2.3. 파이프라인 규칙 (화이트리스트 방식)

- 위키 문서의 Frontmatter에 `published: true` (또는 `publish: true`)가 있는 문서만 빌드 타임에 추출한다. (구현 완료: `migrate-notes.mjs`)
- **[To-Do] AI 편집장(Paperclip Agent) 파이프라인**:
  - `status: seed` 이면서 `published: true` 인 글이 위키에 올라오면,
  - Paperclip 에이전트가 이를 감지하여 문맥을 읽고, 블로그 톤앤매너에 맞게 윤문/교정하여 PR을 생성한다.
  - 사람이 PR을 Merge하면 `status`가 `evergreen`으로 승격된다.

## 3. 시리즈(Series) 시스템 기획

### 3.1. 목적

- 하나의 주제로 이어지는 여러 개의 노트를 선형적(Linear)으로 읽을 수 있게 묶어준다.
- 산발적인 정원(Garden)의 링크 구조 안에서도, 작성자가 의도한 '연재물'의 흐름을 잃지 않게 한다.

### 3.2. 데이터 스펙 (Frontmatter)

- `series`: (문자열) 속해 있는 시리즈의 고유 식별자 또는 이름 (예: "design-system-building")
- `seriesOrder`: (숫자) 시리즈 내에서의 순서 (예: 1, 2, 3)

### 3.3. UI/UX 구현 명세 (To-Do)

**A. 글 상세 페이지 (Detail Page)**

- (구현 완료) 글 상/하단에 `SeriesNav` 컴포넌트 노출 (이전 글 / 다음 글 링크).
- **[추가 필요]** 우측 사이드바(TOC 아래 등)에 "이 시리즈의 다른 글 목록"을 렌더링하는 미니 패널 추가.

**B. 시리즈 인덱스 페이지 (`/series` 또는 `/collections`)**

- 블로그 상단 네비게이션(TopBar)에 `Series` 메뉴 추가.
- 넷플릭스나 유튜브 재생목록처럼, 현재 연재 중이거나 완결된 시리즈들의 '커버 이미지'와 '진행률(3/10)'을 보여주는 타일(Grid) UI 구축.
- 특정 시리즈 타일을 클릭하면, 그 시리즈에 속한 글들이 1번부터 차례대로 정렬된 리스트 페이지로 랜딩.

## 4. 모바일 및 추가 사용성 (v2 백로그)

### 4.1. 세계관 가이드 (Onboarding)

- 랜딩 페이지 또는 `/about` 페이지 하단에 블로그의 세계관(Seed -> Evergreen)을 설명하는 시각적 인포그래픽 추가.
- 뱃지(`Evergreen`, `Seed`)를 클릭하면 해당 상태의 글만 모아보는 필터 쿼리 기능 추가 (`/blog?status=evergreen`).

### 4.2. 모바일 사용성 (BottomSheet & FAB)

- 모바일 뷰에서 글 우측의 4단 사이드바(TOC, 백링크, 그래프 등)를 하단 FAB(Floating Action Button)로 숨김 처리.
- FAB 클릭 시 디자인 시스템에 추가된 `BottomSheet` 컴포넌트가 올라오며 목차/백링크 탐색 제공.
